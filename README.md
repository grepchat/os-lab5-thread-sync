# Практическое занятие №5 — Средства синхронизации потоков

Реализация на C# (.NET 9, WinForms) вместо Delphi.

| Задание | Объект синхронизации | Класс .NET |
|---|---|---|
| 5.2.1 | Критическая секция | `Monitor` (`lock`) |
| 5.2.2 | Mutex | `System.Threading.Mutex` |
| 5.2.3 | Event | `ManualResetEvent` |
| 5.2.4 | Семафор | `System.Threading.Semaphore` |

## Запуск

```
dotnet run -c Release
```

Start — запуск / возобновление потоков, Finish — приостановка, повторное нажатие — завершение
потоков и освобождение объекта синхронизации.
